端侧智能体

以真实应用，衡量研究价值。

从研究原型到实际应用

欢迎围绕真实设备与业务场景开展联合研究。

目前主要研究内容

  1. 01

    端侧原生模型架构 Device-Native Model Architectures

    面向内存、带宽与能耗约束，协同设计端侧模型结构与推理方法。

  2. 02

    训练与推理架构生成 Vibe Infra

    以硬件与模型为输入，由 Agent 自动构建专用训练和推理架构。

  3. 03

    端侧记忆 On-Device Memory

    构建可检索、可更新、可遗忘的本地记忆，支持智能体持续个性化。

  4. 04

    智能体规模化协同 Agent Scaling

    研究 Agent 规模扩展下的协作机制，让任务能力随规模提升，同时控制通信与调度开销。
